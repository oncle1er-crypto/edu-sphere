# Guide d'utilisation - Bulletins de paie du personnel

Ce guide décrit le parcours complet à suivre chaque mois pour obtenir des bulletins fiables. Un bulletin ne doit pas être validé tant qu'une alerte subsiste dans l'aperçu.

## 1. Vérification initiale des paramètres RH

1. Ouvrez **Enseignants > Configuration**.
2. Vérifiez les paramètres sociaux et fiscaux applicables à l'établissement :
   - nombre d'heures mensuelles ;
   - plafond mensuel CNPS ;
   - taux CNPS salarié ;
   - taux CNPS employeur ;
   - prestations familiales ;
   - assurance maternité ;
   - accident du travail ;
   - CMU salarié et employeur ;
   - contribution employeur ;
   - taxe d'apprentissage ;
   - formation professionnelle ;
   - barème fiscal ;
   - barème d'ancienneté.
3. Faites confirmer les taux réglementaires par la personne responsable de la paie ou le conseil comptable de l'établissement. Les taux configurables ne doivent pas être remplacés par ceux d'un ancien fichier Excel sans vérification.
4. Enregistrez toute correction avant de préparer le mois.

## 2. Compléter la fiche de chaque membre du personnel

1. Ouvrez **Enseignants > Personnel**.
2. Sur la ligne de l'agent, choisissez **Voir la fiche**.
3. Vérifiez au minimum :
   - nom et prénoms ;
   - matricule ;
   - poste et département ;
   - type de contrat ;
   - date d'embauche ;
   - salaire brut de base ;
   - numéro CNPS ;
   - numéro CMU ;
   - nombre de parts fiscales ;
   - banque et RIB, si utilisés.
4. Ouvrez le contrat actif et vérifiez le salaire de base, la quotité et les primes. Le contrat actif est prioritaire sur le salaire renseigné dans la fiche.
5. Enregistrez les corrections.

## 3. Préparer les bulletins du mois

1. Ouvrez **Enseignants > Paie**.
2. Sélectionnez le mois et l'année concernés.
3. Cliquez sur **Fiches de paie du mois**.
4. Sélectionnez de nouveau la période dans la fenêtre de préparation.
5. Cliquez sur **Vérifier les variables du mois**.
6. Contrôlez le résultat de l'aperçu :
   - **Prêt** : la fiche contient les informations nécessaires ;
   - **À corriger** : ouvrez la fiche concernée et corrigez chaque alerte ;
   - **Déjà créé** : un bulletin existe déjà pour cet agent et cette période.
7. Vérifiez le net estimé global.
8. Ne poursuivez pas si un agent attendu est absent, si un salaire est nul ou si une alerte importante demeure.
9. Cliquez sur **Créer les brouillons**.

Cette opération crée les bulletins et archive leurs lignes de calcul. Elle ne les valide pas et ne les marque pas comme payés.

## 4. Contrôler chaque brouillon

1. Dans le tableau de paie, cliquez sur la ligne d'un agent pour afficher le détail.
2. Contrôlez séparément :
   - les gains ;
   - les retenues salariales ;
   - les charges patronales ;
   - les bases et taux appliqués ;
   - le net à payer ;
   - le coût employeur.
3. Comparez les éléments variables du mois avec les pièces justificatives : prime, absence, acompte ou retenue exceptionnelle.
4. Cliquez sur **Bulletin PDF** pour produire le document de contrôle.
5. Un filigrane **BROUILLON - NON VALIDÉ** apparaît tant que le bulletin n'est pas validé.
6. Si l'application détecte une divergence entre les lignes et les totaux, le PDF est bloqué. Il faut corriger ou régénérer le bulletin ; il ne faut pas contourner ce contrôle.

## 5. Lire le bulletin PDF

Le document contient :

1. l'identité et les coordonnées de l'établissement ;
2. le mois et les dates exactes de la période ;
3. l'identification professionnelle du salarié ;
4. le détail des gains, retenues et contributions employeur ;
5. les bases et taux de calcul ;
6. les totaux et le net à payer ;
7. le coût employeur, affiché à titre informatif ;
8. le brut imposable et la base CNPS ;
9. les cumuls depuis janvier jusqu'au mois du bulletin ;
10. la date réelle de paiement lorsqu'elle existe ;
11. les zones de signature du salarié et de l'employeur.

## 6. Valider le bulletin

1. Revenez au tableau de paie.
2. Après contrôle complet, cliquez sur **Valider**.
3. Confirmez que le statut devient **Validé**.
4. Régénérez le PDF si vous devez remettre une version sans filigrane de brouillon.

La validation signifie que les données du bulletin ont été contrôlées. Elle doit intervenir avant le paiement.

## 7. Enregistrer le paiement

1. Sur un bulletin validé, cliquez sur **Marquer payé**.
2. Lisez le message de confirmation.
3. Confirmez uniquement lorsque le salaire a réellement été payé.
4. Vérifiez que le statut devient **Payé**.
5. Générez le PDF définitif : la date réelle de paiement y apparaît.

Cette action crée automatiquement les dépenses comptables liées au net versé et aux charges patronales. Elle est définitive dans le parcours normal.

## 8. Imprimer et archiver

1. Cliquez sur **Bulletin PDF**.
2. Ouvrez le fichier téléchargé.
3. Vérifiez une dernière fois le nom, la période, le net et la date de paiement.
4. Imprimez en A4 à l'échelle **100 %** ou **Taille réelle**.
5. Faites signer le salarié et apposer le cachet de l'établissement.
6. Remettez un exemplaire au salarié.
7. Archivez l'exemplaire employeur selon la procédure interne de l'établissement.

## 9. Export mensuel de contrôle

1. Sélectionnez le mois et l'année.
2. Cliquez sur **Tout exporter**.
3. Conservez le fichier CSV avec le dossier mensuel de paie.
4. Comparez le total brut, les retenues, le net, les charges patronales et le coût employeur avec la comptabilité.

## 10. Que faire en cas d'erreur

- **Salaire absent** : compléter le contrat actif ou le salaire de base de la fiche.
- **Ancienneté incorrecte** : corriger la date d'embauche, puis recréer le brouillon.
- **CNPS ou CMU incorrecte** : vérifier les paramètres RH et les identifiants de l'agent.
- **Impôt incorrect** : vérifier les parts fiscales et le barème fiscal configuré.
- **Prime absente** : vérifier les primes du contrat actif.
- **PDF bloqué pour incohérence** : ne pas valider ; contrôler les lignes archivées et recréer le brouillon après correction.
- **Bulletin déjà créé** : contrôler le bulletin existant au lieu d'en créer un second.
- **Mauvaise période** : sélectionner le bon mois avant la préparation et avant l'impression.

## Liste de contrôle finale

Avant la remise du bulletin, les réponses suivantes doivent toutes être **Oui** :

- Les taux ont-ils été vérifiés ?
- La fiche du salarié est-elle complète ?
- Le contrat actif est-il correct ?
- L'aperçu ne contient-il aucune alerte bloquante ?
- Les gains et retenues du mois ont-ils été contrôlés ?
- Le net à payer est-il cohérent ?
- Le bulletin a-t-il été validé avant paiement ?
- Le paiement a-t-il été marqué uniquement après le versement réel ?
- Le PDF définitif affiche-t-il la bonne période et la bonne date de paiement ?
- Les signatures et l'archivage ont-ils été effectués ?
