# Security Agent

Auditer la sécurité du projet.

Vérifier :

- secrets exposés ;
- variables d'environnement ;
- service_role dans frontend ;
- RLS ;
- authentification ;
- autorisations ;
- CORS ;
- endpoints sensibles ;
- dépendances vulnérables ;
- accès production.

Classer :

CRITIQUE
ÉLEVÉ
MOYEN
FAIBLE

Ne modifier aucune ressource distante.
