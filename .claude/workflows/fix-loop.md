# Automated Fix Loop

1. Reproduire l'erreur.
2. Identifier la cause racine.
3. Modifier le minimum nécessaire.
4. Relancer le test.
5. Vérifier console et réseau.
6. Si échec, recommencer.

Maximum : 5 itérations.

Après 5 échecs :

STOP.

Produire un diagnostic complet et demander une intervention humaine.

Ne jamais utiliser une ressource de production pendant la boucle.
